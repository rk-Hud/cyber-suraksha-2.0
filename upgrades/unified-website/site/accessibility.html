Accessibility statement

Accessibility goals, current limitations and the route for non-sensitive feedback.

This policy and governance information is currently published in English; translated navigation does not mean the full page is translated.

Our design goals

The public pages use semantic headings, language selection, accessible form labels, keyboard navigation, a skip-to-content link, responsive layout and reduced-motion styles. The target for any formal deployment is applicable GIGW 3.0 accessibility provisions and WCAG 2.1 AA assessment.

These goals are not certification. An independent accessibility audit, screen-reader tests, contrast checks and mobile assistive-technology testing have not been completed.

Current limitations

The core scam-awareness tools have English, Telugu and Hindi options, but these newly added governance and policy pages are currently provided in English only. Complete human-reviewed translations, language tagging of mixed-language passages and usability testing remain open work.

Report an accessibility difficulty

For non-sensitive feedback, open the contact page and use the project issue tracker. Do not submit private records there. Service-level commitments and an agency accessibility officer will need to be designated before any official operation.
