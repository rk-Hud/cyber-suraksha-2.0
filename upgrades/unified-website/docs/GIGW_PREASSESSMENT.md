# India GIGW 3.0 — Preliminary Gap Assessment

**This is not a GIGW certification.** Government-owned sites require formal authorization, appropriate government domain/identity, user-centric content, accessibility and security processes as applicable.

| Area | Software evidence | Open gap |
|---|---|---|
| Ownership | Named independent project leader and governance pages | Government sponsor/official ownership not established |
| Content | Practical India-specific safety guidance, external government links | Formal departmental review, publishing policy, lifecycle review |
| Accessibility | Responsive pages and landmark-based HTML; core lessons in 3 languages | Full WCAG and official accessibility audit missing |
| Security | Read-only public mode, static headers, local role/CSRF boundaries | NIC/STQC/CERT-In empanelled independent security assessment as applicable; pen testing missing |
| Data/Privacy | No public message upload; dummy records only | Legal privacy assessment, retention, hosting agreements and security operations |
| Domain identity | Independent Render/GitHub project branding | **Not** eligible to present a gov.in/nic.in domain without government ownership/allocation |
| Availability | Local WSGI run and optional read-only hosting config | Performance, DR, uptime/incident processes and approved infra not established |
| Accountability | Source, risk register and test report | Independent governance, public contact/feedback process and audit ownership |

Official GIGW guidance: https://guidelines.india.gov.in/guidelines/
STQC CQW scheme: https://www.stqc.gov.in/website-quality-certification-0
