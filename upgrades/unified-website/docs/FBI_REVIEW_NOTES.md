# U.S. FBI and International Technical Review Notes

The FBI's official business innovation channel describes a process for submitting information, a capability statement or unsolicited proposal to be evaluated by FBI subject matter experts. Evaluation is not approval, adoption, procurement, federal cybersecurity certification, a promise of a contract or an operational integration.

Official channel: https://biz.fbi.gov/fits/how-to-begin

An initial proposal should describe the problem and use case, non-confidential technical capabilities, independently testable software, data-flow and privacy boundaries, security risks, limitations and proposed evaluation setup. It must not imply FBI partnership or request exchange of confidential federal investigative material through this non-authorized independent web app.

International agencies apply their own procurement, security authorizations, data-protection rules, language/accessibility requirements, infrastructure controls and contracts. The platform is not globally approved by any single technical certificate.
