# CYBER SURAKSHA 2.0 — approximately four-minute video script

Record the screen while running the local Flask app. Use synthetic data only. Keep the address bar visible when showing the local demo. Do **not** pretend it is a live government service.

**0:00–0:35 — Introduction / problem**  
"Namaste. This is CYBER SURAKSHA 2.0, built for the Hack for Social Cause theme Digital Safety and Cyber Fraud Awareness. People encounter fake links, impersonation and UPI scams. Many need simple guidance about safe choices and how to use official reporting channels."

**0:35–1:15 — Dashboard and sample reporting**  
"Our first feature is a fictional reporting workflow. It shows how a report is structured, assigned a reference and displayed in an incident register. All examples are synthetic. This prototype does not transmit complaints to police or banks."

**1:15–1:55 — Fraud simulator**  
"The financial fraud simulator presents fictional decisions, including UPI collect-request scams. A learner chooses actions and sees feedback on safer responses, such as verifying independently and not sharing OTPs or PINs."

**1:55–2:35 — SOC investigation and Zero Trust**  
"Our SOC module demonstrates investigating fictional security alerts by reviewing evidence and documenting an analyst's assessment. Zero Trust simulation demonstrates identity, device and access-policy decisions. These are educational simulations, not live defenses."

**2:35–3:10 — Awareness and languages**  
"The awareness centre offers lessons and a quiz in English, Hindi and Telugu, improving accessibility for learners. We explain the official cybercrime helpline 1930 and cybercrime.gov.in."

**3:10–3:45 — Technology and validation**  
"The web application uses Python, Flask, SQLite, HTML, CSS and JavaScript. Its source code, documentation and tests are in our GitHub repository. The public demonstration is configured as read-only to avoid collecting personal data."

**3:45–4:05 — Impact and closing**  
"Our next steps are user testing, better accessibility and evaluation of learning outcomes. We aim to help students and citizens recognize fraud and respond quickly. Thank you."

**Recording checklist:** horizontal video; clearly visible browser; 3–5 minutes if required by current rules; file size below the current portal limit; no actual victim data or ID documents; no false integration claims. Use your own voice and review accuracy before submitting.
