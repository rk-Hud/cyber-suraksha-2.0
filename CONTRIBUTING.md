\# Contributing to CYBER SURAKSHA 2.0



Thank you for your interest in contributing to CYBER SURAKSHA 2.0.



CYBER SURAKSHA 2.0 is an educational cybersecurity project designed to improve cyber-fraud awareness and demonstrate basic cybercrime prevention and response workflows.



\## How You Can Contribute



You can contribute by:

\- Reporting bugs and suggesting improvements.

\- Improving the user interface and accessibility.

\- Adding English, Hindi, and Telugu awareness content.

\- Improving documentation and setup instructions.

\- Adding safe, fictional cyber-fraud scenarios.

\- Writing or improving automated tests.



\## Contribution Guidelines



1\. Keep contributions beginner-friendly and easy to understand.

2\. Use clear Python, HTML, CSS, and JavaScript code.

3\. Avoid unnecessary changes to existing functionality.

4\. Use only fictional or sanitised sample data.

5\. Explain the purpose of significant changes.



\## Testing



Before submitting changes:



1\. Install the project dependencies.

2\. Run the Flask application locally.

3\. Test the affected modules.

4\. Run the available automated tests.

5\. Update the manual test checklist when necessary.



\## Security and Privacy



\- Never submit real passwords, OTPs, PINs, banking details, or victim information.

\- Never publish API keys, access tokens, or other secrets.

\- Do not test against systems without permission.

\- Report security concerns responsibly.



\## Project Limitations



CYBER SURAKSHA 2.0 is an educational prototype. It is not an official police, bank, CERT-In, or government reporting platform. It does not provide live threat detection, automatic payment blocking, or real-world incident response.
