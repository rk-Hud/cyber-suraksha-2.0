# Contributing

Thank you for helping improve CYBER SURAKSHA 2.0.

## Ground rules

- Keep contributions educational, defensive and lawful.
- Do not add real victim data, credentials, secrets, live targets or private reports.
- Do not describe simulated features as operational integrations.
- Keep changes beginner-readable and document new modules.
- Add or update automated tests when behaviour changes.

## Local development

1. Create a virtual environment and install `requirements.txt`.
2. Run the app locally with `python app.py`.
3. Run `python -m unittest discover -s tests -v` before submitting changes.
4. Explain the problem, change, test performed and any known limitation in your pull request.

## Pull requests

Use a clear title, keep each change focused, include screenshots only when they contain synthetic data, and never include `.venv/`, `.env` or a populated SQLite database.
