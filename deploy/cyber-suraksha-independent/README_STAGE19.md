# CYBER SURAKSHA 2.0 — Independent Preview App

Scope: Independent public cyber safety awareness; no government affiliation, police intake or real complaint storage.

## Render preview settings (new service, not the existing Flask services)

- Repo: `https://github.com/rk-Hud/cyber-suraksha-2.0`
- Branch: freshly created `release/cs20-independent-...` generated by `PUBLISH_NEW_BRANCH_WINDOWS.ps1`
- Root directory: leave blank (this preview app is in a subfolder).
- Runtime: Python, region: Singapore, plan: Free (subject to account availability).
- Build command: `pip install -r deploy/cyber-suraksha-independent/requirements.txt`
- Start command: `cd deploy/cyber-suraksha-independent && uvicorn main:app --host 0.0.0.0 --port $PORT --no-access-log`
- Health check path: `/api/v1/health`
- Environment: `PYTHON_VERSION=3.12.7`, `CS20_HTTPS_HSTS=1`
- Auto-deploy: **OFF**; no manual deployment until branch reviewed.

The training SQLite database is created from fictional fixtures when the app starts. Local instance storage is disposable on hosted free plans. Do not use for police complaints or real personal records.
