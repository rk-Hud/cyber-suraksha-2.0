# Security and vulnerability reporting

CYBER SURAKSHA 2.0 is an independent cyber-safety awareness preview. No real citizen complaint intake or administrator portal is active here.

For responsible disclosure, review the repository security page: https://github.com/rk-Hud/cyber-suraksha-2.0/security . Private vulnerability reporting is subject to repository configuration; do not publish private information in public issues.

No authorization is granted to access other accounts or test third-party services. Do not submit secrets, live incident details or victim information.
