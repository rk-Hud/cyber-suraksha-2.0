# Software copyright — preparation checklist

**Working description:** Cybersecurity awareness and controlled owner-operations software, with multilingual content and educational components.  
**Repository:** `rk-Hud/cyber-suraksha-2.0`

> This is a preparation worksheet, **not** Form XIV, an official application, a copyright certificate or proof that registration was filed. Confirm all facts and current requirements using the Copyright Office's official site before submission.

## 1. Establish what is being claimed

Copyright can protect eligible original expression in source code and content; it does not automatically give exclusive rights to the website name, underlying ideas, methods, algorithms as abstract ideas, or third-party contributions. A complex site may include separate software, literary, artistic and licensed works.

Before applying, identify the precise software version, relevant human authors, contributions, rights transfers if any, and ownership of each claimed component. **Do not declare sole authorship of material someone else authored or of third-party code.** Authorship, contribution and publication statements must reflect the actual facts.

The repository's current top-level `LICENSE` is MIT. That is distinct from government copyright registration. Record any existing license grants and third-party obligations; registration does not by itself cancel permission already granted under MIT.

## 2. Evidence to preserve securely

- Exact Git commit SHA and a dated immutable copy of the claimed release.
- Source tree with the origin of each owned module documented.
- Code contributions, development notes, creation dates and version history as available.
- Documentation, diagrams, original designs, original text and graphics for separate assessment.
- Third-party dependency and asset license inventory, with permissions where required.
- Proof supporting any claimed first-publication date, country and publisher.
- Applicant and author identification details, addresses, nationality and contact details.
- Ownership transfer or commissioning agreements, if they exist.

Keep personal identity documents and sensitive filing materials **outside this repository**.

## 3. Software filing deposit

The Indian Copyright Office's software guidance requests **first and last 10 pages of source code** (or all pages if there are fewer than 20) in a PDF under 10 MB, without obscuring the required submitted code. Requirements may be updated, so check the current official instructions.

A software filing may also require **object code**. For a web application, identify which machine-readable or compiled artefacts represent the actual claimed software and seek clarification from the Copyright Office if the appropriate format is uncertain.

**Safety:** Before preparing a source-code deposit, check that files do not contain live secrets, credentials, keys, tokens, personal case records or unnecessary confidential data. Do not upload sensitive materials to a public GitHub repository. Resolve the conflict between official deposit instructions and any confidential data by following the Office's instructions, not by submitting fabricated or silently altered code.

## 5. Filing workflow

1. Review the official copyright.gov.in instructions and current fees.
2. Confirm the precise work and authorship to be claimed.
3. Assemble and inspect the required deposit documents.
4. Complete the official application forms accurately.
5. Sign where required and upload them through the official registration portal.
6. Pay the prescribed fee and preserve the acknowledgement and diary number.
7. Monitor for examination requests, objections or missing-document notices.
8. Maintain the filed source/version archive and any issued registration certificate securely.

Useful official starting points:
- [Copyright Office, India](https://copyright.gov.in/)
- [Online services](https://copyright.gov.in/UserRegistration/BOLoginPage.aspx)

The independent nature of the project does **not** confer any government approval, official status, guaranteed patentability or unrestricted rights to third-party content.
