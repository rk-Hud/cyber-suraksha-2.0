# GitHub publication checklist

- [ ] Confirm you own or have permission to publish all source code, images, fonts and other assets.
- [ ] Run the application from a clean clone on Windows.
- [ ] Install dependencies and run the automated test suite; save the actual output.
- [ ] Complete the manual acceptance checklist in `docs/TESTING.md`.
- [ ] Review every screenshot and sample file for personal or sensitive data.
- [ ] Confirm `.env`, `.venv`, SQLite databases, backups and logs are not staged.
- [ ] Check that README claims match the current application.
- [ ] Decide whether the MIT licence is appropriate for your ownership and project goals.
- [ ] Add repository description, topics and a suitable project screenshot (synthetic data only).
- [ ] Review the final Git diff and commit history before making the repository public.
